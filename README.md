# ИКАР (IKAR)

Интеллектуальная система управления задачами с голосовым помощником.

## Структура проекта

- apps/api — серверная часть и REST API.
- apps/web — веб-интерфейс.
- apps/desktop — desktop-голосовой помощник.
- database — структура и миграции базы данных.
- docs — документация проекта.

## Технологии

- Frontend: React, TypeScript.
- Backend: Node.js, Express, TypeScript.
- Database: PostgreSQL.
- Desktop Assistant: Python.
